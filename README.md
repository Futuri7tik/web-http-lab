# web-http-lab

Проект-лабораторная по курсу "Python Backend Developer Pre-Trainee"
## Запуск проекта

Для запуска приложения нужно:

### 1. Создать и активировать виртуальное окружение
* **Для Linux / macOS:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
* **Для Windows:**
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```

### 2. Установить зависимости
```bash
pip install -r requirements.txt
```

### 3. Запустить сервер разработки
```bash
uvicorn main:app --reload
```

## Эндпоинты API

Интерактивная документация (Swagger UI) доступна автоматически после запуска сервера по адресу:
```
http://127.0.0.1:8000/docs
```

### Основные маршруты

| Метод | Эндпоинт | Статус-код | Описание |
| :--- | :--- | :---: | :--- |
| **GET** | `/health` | `200 OK` | Проверка работоспособности сервиса. Возвращает статус приложения. |
| **GET** | `/hello` | `200 OK` | Приветственный эндпоинт. Возвращает приветственное сообщение. |
| **GET** | `/notes` | `200 OK` | Получение списка всех существующих заметок. |
| **POST** | `/notes` | `201 Created` | Создание новой заметки. Требует валидации полей `title` и `content`. |
| **GET** | `/notes/{note_id}` | `200 OK` / `404` | Получение детальной информации о заметке по её уникальному `id`. |
| **HEAD** | `/notes/{note_id}` | `200 OK` / `404` | Проверка существования заметки без скачивания её тела. Возвращает заголовок `x-note-exists: true`. |
| **PATCH** | `/notes/{note_id}` | `200 OK` / `404` | Частичное обновление полей заметки (`title` и/или `content`). |
| **DELETE** | `/notes/{note_id}` | `204 No Content` / `404` | Удаление заметки по её `id`. Ответ не содержит тела. |

## Ограничения

### Сброс данных при перезапуске

Все данные хранятся в памяти и будут сброшены при перезапуске сервера
